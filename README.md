Este repositorio contiene las actividades desarrolladas en C# utilizando Aplicaciones de Consola (.NET) enfocadas en la programación orientada a objetos y encapsulamiento profesional.

## Estructura del Repositorio

* **Actividad #1: Estructura de Clases e Instanciación**
  * **Descripción:** Creación de una clase formal con un método público para mostrar un mensaje de bienvenida fijo en pantalla, gestionando su ejecución automática desde el punto de entrada principal del programa.
  * **Componentes clave:** Estructura de un programa por consola, método `Main`, instanciación de objetos con el operador `new` y estándares de nomenclatura PascalCase.

* **Actividad #2: Modularidad y Parámetros**
  * **Descripción:** Programa interactivo que solicita al usuario el ingreso de datos por teclado y los transmite como argumentos hacia un método con parámetros para personalizar la salida de la consola.
  * **Componentes clave:** Entrada y salida de datos (`Console.ReadLine`), paso de parámetros y formateo mediante marcadores de posición por índice `{0}`.

* **Actividad #3: Variables de Instancia y Propiedades**
  * **Descripción:** Implementación de ocultamiento de información protegiendo los atributos internos de la clase mediante accesos controlados y seguros para su lectura y modificación.
  * **Componentes clave:** Modificadores de acceso `private` y `public`, variables de instancia, descriptores de acceso `get` y `set` con la palabra implícita `value`.
